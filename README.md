# Port Scanner

A Python tool that checks which common ports are open on your own machine or network.

## Features

- Checks 15 common ports quickly using threads
- Labels each open port with its service name
- Only for devices you own or have permission to test

## Requirements

- Python 3.8 or newer
- No extra libraries needed

## Usage

```
python port_scanner.py 127.0.0.1
```
